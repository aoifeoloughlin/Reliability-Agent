# Set up Reliability Agent on Linux VM

## Requirements

Oracle VirtualBox 

On boot up select "Ubuntu (safe graphics)"

Exit the "Ubuntu" set up pop up

Open the web browser for VM

Open "Terminal" in Apps

With sudo install the following technologies into the VM:
- Git
- Python3
- pip3 (sudo apt update and then sudo apt install pip3 -y)

With pip3 install:
- psutil
